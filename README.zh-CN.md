# Minimal New Tab

一个简洁的 Chrome 新标签页。默认空白，可选显示书签网格，跟随系统主题。

[English](README.md)

## 功能

- 默认空白 —— 没有新闻、没有小组件、没有杂念
- 可选书签网格，默认关闭
- 按文件夹分组显示图标卡片
- 只显示图标，鼠标悬停显示标题
- 折叠时显示 15 个，展开时显示 31 个
- 超过 31 个书签的文件夹显示 `+N more` 提示
- 跟随系统深浅色模式
- 自动缩放适配视口，永不滚动
- 书签变化时实时刷新

## 安装

1. 克隆或下载本仓库。
2. 在 Chrome 里打开 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选择项目文件夹。

## 配置

让 Chrome 启动时打开这个页面：

1. 打开 `chrome://settings/onStartup`
2. 选择 **打开新标签页**

隐藏 Chrome 自带的书签栏（可选，推荐）：

1. 打开 `chrome://settings/appearance`
2. 把 **显示书签栏**设为 **从不**

## 使用

打开新标签页，默认是一片空白。

显示书签：

1. 鼠标移到右下角。
2. 点齿轮图标。
3. 打开 **Bookmarks** 开关。

书签栏里的文件夹会以卡片形式呈现。点卡片上的 `+N` 可以展开。

## 权限

- **`bookmarks`** —— 读取书签栏，渲染卡片
- **`favicon`** —— 通过 Chrome 本地图标服务获取网站图标
- **`storage`** —— 保存设置
